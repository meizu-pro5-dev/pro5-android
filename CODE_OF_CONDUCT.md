# Code of Conduct

This project follows the
[Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We keep the community open and welcoming. We do not tolerate harassment of any
kind, personal attacks, or conduct that makes contributing unsafe.

## Scope

This applies to issues, pull requests, discussions, and any other project
space.

## 中文说明

本项目遵循 Contributor Covenant 行为准则。请保持社区开放友好；不接受任何
形式的骚扰、人身攻击或让贡献者感到不安全的行为。
